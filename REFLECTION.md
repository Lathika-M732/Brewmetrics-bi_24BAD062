# Reflection

This project provided hands-on experience in building a Business Intelligence solution using Power BI, GitHub, and GitHub Copilot. Copilot was useful in generating DAX measures such as Total Sales, Running Total, Month-over-Month Growth, and City Rank. Some suggestions were directly usable, while others required validation and small modifications to ensure they matched the data model.

The star schema approach improved data organization by separating transaction data from dimension tables. This made report development easier and improved model clarity. Creating relationships between Fact_Sales, Dim_Date, Dim_City, and Dim_Product helped support efficient analysis.

Using GitHub introduced a version-controlled workflow that was different from traditional Power BI labs. Instead of building everything at once, progress could be tracked through commits. This made it easier to understand changes and maintain project history.

The final dashboard successfully presents monthly sales trends, product performance, city performance, and interactive filtering. Overall, the project improved my understanding of Power BI modeling, DAX calculations, dashboard design, and AI-assisted development workflows.
